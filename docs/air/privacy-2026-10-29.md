# Air privacy consistency — 29 October 2026

Air 1.2.5 aligns Cloakyard, CloakPDF, CloakDrop’s website, CloakResume and CloakRoll’s
website. This is a bounded public-policy and navigation change, not full product or
physical-device acceptance. CloakIMG remains parked and unchanged by explicit user direction.

## What changed

| Surface      | Before                                                                                 | After                                                                                   |
| ------------ | -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| Cloakyard    | Privacy led to the principles section.                                                 | Dedicated directory policy with a real home link.                                       |
| PDF          | Numbered labels, facts grid and narrow single column; icon-only header return.         | Shared reading page, contents, visible Back to CloakPDF and reloadable privacy link.    |
| Drop website | Independent policy CSS and contents treatment.                                         | Canonical policy anatomy; root Markdown, all nine sections and revision preserved.      |
| Resume       | Public policy opened in a modal; landing typography leaked into reading.               | Public reading page, real home link, shared policy content with the safe editor dialog. |
| Roll website | Separate copy/provenance system, different title/date/contents and no explicit return. | Same policy page; joins canonical bundle/checks; old duplicate Air package removed.     |
| Footer       | Current Privacy marked only on Astro sites.                                            | Same accessible current-page state and neutral 1px underline across five sites.         |

The recipe owns return-link geometry, title/lead/date, 14rem contents/65ch reading
measure, responsive stacking, section rhythm and neutral links. The back link uses
ArrowLeft; other directional hyperlinks keep ArrowUpRight. Product claims, section
order and existing revision dates remain intact. The new directory policy is dated
29 October. No library, lockfile, native app, editor output, template or export code changed.

Removed duplicate PDF/Drop/Roll policy skins, the public Resume modal wiring, PDF’s
obsolete privacy navigation callback and Roll’s separately copied Air manifest/assets.
The editor dialog reuses the public policy body and retains its existing lifecycle.
Authoritative Drop/Resume artwork appendices no longer mention retired playback controls.

privacy pass does not push, merge or deploy. Prior deployed releases stay unchanged.

review that separate work before any future whole-dev release. Roll’s native release
and hardware gates remain open. IMG is unchanged; sync deliberately retains its
previous pinned revision until its redesign. Preserve the separate Resume worktrees.

Resume export intermittency and physical/assistive/hardware gates remain open.
