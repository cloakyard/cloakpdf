One language. Different kinds of work.

Browse, drop and paste share the same selection rules. Invalid files leave the previous selection intact. Cancel stops the read; retry starts it again with the same file.

Each product keeps its own supported formats, size limits and recovery choices. Image decoding, encrypted PDFs and résumé imports need their own verified adapters before this pattern reaches an app.
